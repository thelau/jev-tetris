# Other pieces considered

Parked, not abandoned. Glow Tetris is the one being built.

The constant constraint: JEV reads text and nothing else, so every one of these
is really the same question — how do you turn this thing into words?

| Piece | What it is | What JEV makes possible | Effort |
|---|---|---|---|
| **Ask it twice** | Every judgement asked in two phrasings that mean the same thing; the page shows only the gap between the two answers | You can only subtract two answers if they are numbers. Built entirely out of the published framing-sensitivity defect | An afternoon |
| **A history with no timeline** | It reads dates as text and has no chronology. Give it a real timeline and let it order events anyway | The blind spot is documented and stable enough to compose with rather than fight | An afternoon |
| **Portrait in 255 questions** | One subject, 255 simultaneous judgements, rendered as a single field. No words, ever | 255 dimensions of one thing in one call, ~300ms, with nothing narrated | An afternoon |
| **Judgment subtitles** | Found footage subtitled with its opinions: `AVOIDING 0.84 · REHEARSED 0.91` | Continuous opinion at video rate. Whisper supplies the text, no second model needed | A day |
| **Parliament** | 64 decisions that must cohere, asked in one parallel call, hung beside the version built coherently | Reproducible incoherence. An LLM's attention makes it agree with itself whether you want it to or not | A day |
| **The Library Walk** | 255 fragments; choose what follows; the answer becomes the next state | 255-way ranked choice in one call. Embeddings give nearness, this gives judgement about succession. The dial is how much past it remembers | A day |
| **The page listens** | Browser mic, twenty axes, live on screen | Affect readout at 3/sec for the price of leaving a lamp on | A day |
| **Move the needle** | Game: twelve emotional axes, a target fingerprint, a text box | Fast enough to feel like a controller, and answers only in numbers, so the target is measurable | A weekend |
| **The Blind Editor** | Code describes each frame numerically; JEV scores twenty aesthetic axes; code cuts the film. It never sees an image | Semantic judgement as a per-frame signal track, like audio. 4,000 frames is minutes and cents | Several days |
| **Edited by hesitation** | Same pipeline, but cut rhythm follows confidence rather than content | Doubt as an exportable number | Comes with the above |

Killed: **The door** — a gate with nothing behind it is a gag, not a piece. The
version worth reviving is the one where being let in makes you the doorman: you
add a condition everyone after you must satisfy, and the door slowly becomes
impossible. That only works because extra questions here are nearly free.
